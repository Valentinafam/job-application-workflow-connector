# Resume Routing

## Strategy

Choose one:

- Volume routing: use stable resume variants by role family.
- Precision tailoring: tailor resume and cover letter for high-fit jobs.

## Tailoring Rules

Tailor only when:

- Fit is high.
- Company or role is high priority.
- User explicitly requests Precision mode.
- Application requires custom answers or a cover letter.

Do not tailor when:

- Role is low fit.
- Stable resume variant is already a strong match.
- Application is low-friction Volume mode.

## Verification

Before submitting:

- Confirm selected resume path.
- Confirm upload succeeded.
- Confirm displayed file name matches the intended resume.
