# 平台支持

## 最适合先测试的平台

LinkedIn Easy Apply 通常最适合第一轮测试，因为表单短、流程相对稳定、提交结果容易确认。

## 其他平台

这个 workflow 可以逐步扩展到：

- SEEK
- Glassdoor
- Greenhouse
- Lever
- Ashby
- Workday
- 公司官网和 ATS 页面

是否能顺利自动化取决于具体页面。遇到长表单、账号登录、浏览器权限、验证码或反自动化检查时，应作为 handoff 交回用户。

## 推荐上线节奏

1. 先跑 lead-finding-only trial。
2. 用少量低风险岗位测试 LinkedIn Easy Apply。
3. 每次只新增一个平台。
4. 把 blocker 和重复问题记录到 dashboard。
5. 高匹配或政府岗位升级为精投模式。
