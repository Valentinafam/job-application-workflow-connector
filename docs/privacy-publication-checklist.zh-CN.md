# 隐私与发布检查清单

发布前请确认：

- 删除真实简历、cover letter、截图和生成过的申请材料。
- 删除候选人姓名、邮箱、电话、地址、签证/工签细节和邮编。
- 删除真实投递日志、提交确认文字、招聘方消息和面试记录。
- 删除 `/Users/...` 这类本地路径。
- 删除浏览器会话、cookies、local storage、缓存和导出的密码。
- 用空模板或少量虚构样例替换真实岗位数据。
- 复用 MIT 材料时保留上游版权和许可证声明。
- 对没有明确许可证的仓库，不要重新分发其源码，除非获得作者书面许可。

运行：

```bash
python3 scripts/check_no_private_data.py .
```

这个脚本只是辅助检查，不是保证。公开前仍然需要人工检查一遍。
