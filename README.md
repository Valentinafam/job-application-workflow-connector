# Job Application Workflow Connector

Bilingual docs: [中文说明](README.zh-CN.md)

A privacy-safe connector that wires together two upstream Codex skills into a repeatable job-search workflow:

- Lead finding and keyword extraction: `Shuboya1030/linkedin-keyword-resume-coach`
- Application tracking and assisted submissions: `yvonnehe772/applypilot`

This repository intentionally contains only dependency setup, workflow glue, templates, and safety rules. It does not include private resumes, application history, browser sessions, cookies, screenshots, or candidate-specific data.

## What This Does

1. Installs local dependencies used by the workflow.
2. Helps install the two upstream skills into Codex.
3. Creates a clean dashboard structure for a job pool and application log.
4. Connects daily lead finding to resume routing, cover-letter generation, and application execution.
5. Supports two application modes:
   - `Volume`: use prebuilt resume variants and submit low-risk applications faster.
   - `Precision`: tailor resume and cover letter, then ask for approval before submission.

## What This Does Not Do

- It does not bypass CAPTCHA, login, 2FA, anti-bot, paywall, or platform controls.
- It does not fabricate work history, immigration status, compensation, education, licenses, or metrics.
- It does not redistribute unlicensed upstream code.
- It does not guarantee support for every job board.

## Platform Support

The workflow is easiest to test on LinkedIn Easy Apply because it has a relatively consistent application flow.

Other sites such as SEEK, Glassdoor, Greenhouse, Lever, Workday, and company ATS pages can be supported only when the browser/apply skill can safely interact with the specific form. Long enterprise ATS flows, CAPTCHA, login changes, or sensitive legal questions should be handed back to the user.

## Quick Start

```bash
./scripts/install_dependencies.sh
./scripts/install_upstream_skills.sh
./scripts/init_workspace.sh ./my-private-job-workflow
```

Then open Codex and use this prompt:

```text
Use this job application workflow connector. Start with onboarding, create my private candidate profile, set application rules, then run a lead-finding-only trial before any real applications.
```

## Repository Layout

```text
config/      Example workflow configuration.
dashboard/   Empty CSV dashboard templates.
docs/        Bilingual workflow, safety, and platform notes.
scripts/     Dependency installation and workspace initialization helpers.
templates/   Candidate profile, answer bank, resume routing, and rules templates.
```

## Privacy Rule

Keep candidate-owned data in a private workspace generated by `scripts/init_workspace.sh`. Do not commit that private workspace to GitHub.

Before publishing changes, run:

```bash
python3 scripts/check_no_private_data.py .
```
